# تحديث 56.2 — حساب أصناف البوفيه حسب عدد الترابيزات

- إضافة حقل «عدد الترابيزات» في تسجيل القاعة وتعديلها.
- لكل صنف داخل باكدج البوفيه طريقة حساب: لكل فرد، لكل ترابيزة، أو كمية ثابتة.
- أمر تجهيز المخزن يحسب الأصناف المشروبات حسب طريقة الحساب المختارة.
- حجز المخزون المرتبط بصنف بوفيه يستخدم طريقة الحساب نفسها.
- يمنع تسجيل حجز بباكدج تحتوي صنفًا محسوبًا لكل ترابيزة إذا لم يتم تحديد عدد الترابيزات للقاعة.
- ترحيل قاعدة البيانات آمن وإضافي: السجلات القديمة محفوظة، والأصناف القديمة تظل محسوبة لكل فرد افتراضيًا.

مثال: قاعة بها 30 ترابيزة، وصنف «إزازة مياه» محدد بكمية 1 وطريقة «لكل ترابيزة» = 30 إزازة في أمر المخزن.
