# إصدار 56.3 — إصلاح حساب مياه البوفيه وبحث أوامر الشغل

## الإصلاحات
- حساب أصناف المياه المسماة مياه/ماء/ماية/مايه/ميه/إزازة/زجاجة على أساس عدد ترابيزات القاعة عند إصدار/تحديث أمر تجهيز المخزن، إلا إذا تم اختيار «كمية ثابتة» للصنف.
- أصناف المشروبات الأخرى تظل حسب طريقة الحساب المحفوظة: لكل فرد، لكل ترابيزة، أو ثابتة.
- إضافة عدد الترابيزات إلى أمر تجهيز القاعة لسهولة المراجعة.
- دعم فلترة أوامر الشغل برقم الحجز الداخلي، وربط البحث برقم هاتف العميل بقائمة الحجز؛ عند اختيار حجز تُعرض أوامر هذا الحجز فقط.
- مسح الفلاتر يعيد عرض جميع أوامر الشغل.

## ملاحظة تشغيل مهمة
بعد استبدال الملفات، افتح قسم «أوامر الشغل»، ابحث عن الحجز، اختره ثم اضغط «إصدار أو تحديث أوامر الشغل» لتحديث أمر المخزن الموجود مسبقًا بكمية المياه الجديدة. تعديل عدد الترابيزات وحده لا يغير أوامر شغل تم إصدارها سابقًا إلا عند تحديثها.

## فحص
تم فحص صياغة `server.js` و`public/app.js` باستخدام `node --check`.
